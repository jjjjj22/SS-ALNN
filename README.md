# SS-ALNN: Spatio–Spectral Adaptive Liquid Neural Network

SS-ALNN is an end-to-end continuous-time spatio–spectral framework for spectral image modeling (multispectral/hyperspectral).  
It is designed to jointly capture **spatial structures** (textures/morphology) and **wavelength-dependent spectral dynamics** (continuous, non-uniform inter-band evolution) in a unified model.
